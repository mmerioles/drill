# drill for android

Kotlin and Jetpack Compose. `core/` is the platform-free engine, heatmap and
inspo (tested in `app/src/test`); `data/` is SQLite, sync and updates;
`timer/` is alarms and notifications; `ui/` is the screens. `core/InspoVideos.kt`
is generated by `scripts/make-inspo.sh`.

```sh
./gradlew test assembleDebug   # needs JDK 17 and the Android SDK
```

Releases are signed with one key (lose it and installs can't update), from
these repo secrets:

| secret | value |
| --- | --- |
| `ANDROID_KEYSTORE_BASE64` | the keystore, base64 |
| `ANDROID_KEYSTORE_PASSWORD` | its password |
| `ANDROID_KEY_ALIAS` | `drill` |
| `ANDROID_KEY_PASSWORD` | the key's password |

Locally, set `ANDROID_KEYSTORE_PATH` and the last three before
`./gradlew assembleRelease`; otherwise release uses the debug key.
